# 部署流程（快速上手版）

> 本文件是「按步骤操作」的部署清单，详细原理与命令说明见 `DEPLOY.md`。
> 开始前请先阅读 **`REPLACE_PLACEHOLDERS.md`**，把源码里所有 `{{...}}` 占位符替换成你自己的真实配置。

---

## 0. 准备清单

| 项目 | 说明 |
|------|------|
| 云服务器 | 1 核 2G 及以上，公网 IP，放行 80 / 443 端口 |
| 域名 | 已完成 ICP 备案，A 记录指向服务器 IP |

## 1. 服务器环境

```bash
# Node.js（推荐 nvm）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc && nvm install 18 && npm install -g pm2

# MySQL（CentOS / Alibaba Cloud Linux 示例）
yum install -y mysql-community-server && systemctl enable --now mysqld
mysql_secure_installation          # 初始化 root 密码

# Nginx
yum install -y nginx && systemctl enable --now nginx
```

## 2. 初始化数据库

已为你合并好**一键建库脚本** `backend/install.sql`（含全部表结构 + 默认管理员 + 种子数据，按官方顺序合并了 `schema.sql` / `schema-module.sql` / `schema-canteen.sql` / `schema-map-pois.sql` / `schema-treehole.sql` / `schema-new-tables.sql` / `seed-new-tables.sql`）。

```bash
cd /www/app.suyu.ink/backend
# 方式一：脚本自动建库（默认库名 campus_service，可自行改脚本首行 CREATE DATABASE）
mysql -u root -p < install.sql

# 方式二：已有库则指定库名导入
# mysql -u root -p <你的库名> < install.sql
```

> ⚠️ `install.sql` 内含 `DROP TABLE IF EXISTS`，重复执行会清空同名表，**仅首次建库使用**。
> 默认管理员账号为 `admin`，默认密码 `Admin@123456`（已写入 `install.sql`），建库后即可直接登录。**上线前务必改强密码。**

## 3. 配置后端环境变量

```bash
cd /www/app.suyu.ink/backend
cp .env.example .env
vim .env
```

关键项（均为占位符，需替换）：
```env
PORT=3000
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=change_me_to_a_database_password
JWT_SECRET=change_me_to_a_random_long_string            # 用 openssl rand -hex 32 生成
WECHAT_APPID=change_me_to_your_wechat_appid
WECHAT_SECRET=change_me_to_your_wechat_secret
DEFAULT_SCHOOL=示例大学
NODE_ENV=production
```
完成后设好权限：`chmod 600 .env`。

## 4. 安装依赖并启动（PM2）

```bash
cd /www/app.suyu.ink/backend
npm install --production

pm2 start src/app.js --name {{PM2_PROCESS_NAME}} --cwd /www/app.suyu.ink/backend
pm2 save
pm2 startup          # 开机自启
```

健康检查：`curl http://127.0.0.1:3000/api/health` 应返回 JSON。

## 5. Nginx 反向代理 + HTTPS

新建 `/etc/nginx/conf.d/app.suyu.ink.conf`：

```nginx
server {
    listen 80;
    server_name app.suyu.ink;

    location /uploads/ { alias /www/app.suyu.ink/backend/uploads/; expires 30d; }
    location /admin   { alias /www/app.suyu.ink/backend/admin/; try_files $uri $uri/ /admin/index.html; }

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 20M;
    }
}
```

```bash
nginx -t && systemctl reload nginx

# HTTPS（certbot 会自动改写配置并加 80→443 跳转）
certbot --nginx -d app.suyu.ink
```

验证：
- 管理后台：`https://app.suyu.ink/admin`
- H5 端：`https://app.suyu.ink/h5`

## 6. 微信小程序上传

1. 用 **微信开发者工具** 打开 `mini-program/` 目录；
2. 在 `mini-program/project.config.json` 填入你自己的 **AppID**（已脱敏为 ``）；
3. 确认 `mini-program/miniprogram/utils/api.js` 中的 `API_BASE = 'https://app.suyu.ink'` 已改为你的域名；
4. 点击「上传」生成体验版 / 提交审核发布。

> 小程序的订阅消息功能需要模板 ID：在微信公众平台 → 订阅消息 →
> 我的模板 中申请，并把 `mini-program/miniprogram` 下各页面里的
> `{{WECHAT_TEMPLATE_ID}}` 替换成你申请到的模板 ID。

## 常见故障

| 现象 | 排查 |
|------|------|
| 后端起不来 | `pm2 logs {{PM2_PROCESS_NAME}} --err`；确认 `.env` 与 MySQL 可达 |
| Nginx 502 | `pm2 status` 看进程是否在跑；`netstat -tlnp \| grep 3000` 看端口 |
| 小程序连不上 | 确认 `utils/api.js` 的域名与 HTTPS 证书有效；微信后台配置「服务器域名」白名单 |
| 订阅消息不弹 | 模板 ID 是否正确、是否在微信后台启用、用户是否已授权 |

更详细的排查见 `DEPLOY.md` 第九章。
