## 三、每个页面包含 4 个文件

```
pages/某页面/
├── 某页面.js      ← 页面逻辑（Page({ data: {...}, methods: {...} })）
├── 某页面.json    ← 页面配置（navigationBarTitleText 等）
├── 某页面.wxml    ← 页面模板（类 HTML）
└── 某页面.wxss    ← 页面样式（类 CSS）
```

**最小页面示例**：
```json
// 某页面.json
{ "navigationBarTitleText": "页面标题" }
```

```html
<!-- 某页面.wxml -->
<view class="container">
  <text>{{title}}</text>
</view>
```

```css
/* 某页面.wxss */
.container { padding: 20rpx; }
```

```javascript
// 某页面.js
Page({
  data: {
    title: 'Hello World'
  },
  onLoad(options) {
    // 页面加载，options 为 URL 参数
  },
  onShow() {
    // 页面显示时
  }
});
```

## 四、API 调用规范

### 4.1 API 客户端位置
所有 API 函数定义在 `utils/api.js`。

### 4.2 调用方式
```javascript
const api = require('../../utils/api');

// 在页面方法中调用
async someMethod() {
  const res = await api.某API方法(参数);
  if (res.success) {
    // 成功处理 res.data
  } else {
    // 失败，res.message 是错误信息
  }
}
```

### 4.4 API 请求/响应格式
```javascript
// 请求（自动携带 JWT Token）
request('POST', '/api/carpools', {
  from: '学校南门',
  to: '火车站',
  time: '2026-07-01 14:00',
  seats: 3,
  price: 10
});

// 响应
{
  success: true,              // 是否成功
  data: { ... },             // 数据（成功时）
  message: '错误信息',        // 提示信息
  total: 100,                // 列表时可能有总数
  page: 1,
  pageSize: 20,
  list: [...]                // 列表数据
}
```

### 4.5 Token 自动管理
- `utils/api.js` 已实现自动 Token 存储（`wx.setStorageSync('token', ...)`）
- 401 时自动尝试刷新 Token，失败则清除登录状态
- 页面无需手动处理 Token

## 五、模块页面（10 个校园模块）架构

这 12 个页面（express, task, lost, forum, secondhand, rental, substitute, print, yellowpage, bulletin, charity, treehole）共享同一套基础逻辑，由 `pages/_shared/base.js` 提供。

### 5.1 模块页面的 JS 文件写法
每个模块页面只需极少代码：

```javascript
// pages/express/express.js 示例
const mixin = require('../_shared/base');
const app = getApp();

Page({
  data: {
    moduleName: 'express',    // ★ 唯一需要指定的：模块标识
    ...mixin.baseData,        // 复制基础数据字段
  },

  onLoad(options) {
    mixin.baseOnLoad.call(this, options);
  },

  onShow() {
    mixin.baseOnShow.call(this);
  },

  ...mixin.baseMethods,       // 复制所有基础方法
});
```

### 5.2 模块配置（定义在 base.js 中）
```javascript
moduleConfig = {
  express:    { icon: '📦', color: '#ff6b35', empty: '还没有快递代取信息', desc: '帮取快递、代寄包裹', tab0: '快递大厅', tab1: '发布代取' },
  task:       { icon: '🎯', color: '#6c5ce7', empty: '还没有悬赏任务', desc: '悬赏求助、互助帮忙', tab0: '任务大厅', tab1: '发布任务' },
  // ... 每个模块有自己的图标、颜色、空状态、描述
};
```

**添加新模块只需在这里加一行配置**。

### 5.3 模块页面的 WXML 模板
模块页面使用 4 个 tab 的 swiper 布局：
- **Tab 0**：列表（帖子大厅）
- **Tab 1**：发布

- **Tab 3**：我的（我的帖子/收藏/反馈）

## 六、常见修改场景

### 场景 A：修改某个页面的样式
**涉及文件**：`pages/某页面/某页面.wxss`

直接修改 CSS，注意单位使用 `rpx`（小程序响应式像素）。

### 场景 B：修改某个页面的功能逻辑
**涉及文件**：`pages/某页面/某页面.js`

找到对应的方法，修改逻辑。可能还需修改 `某页面.wxml` 模板。

### 场景 C：添加一个新的 API 调用
**步骤**：
1. 在 `utils/api.js` 中添加新的 API 方法
2. 在目标页面的 `.js` 中 `require` 后调用

```javascript
// api.js 中添加
async function getHotRoutes() {
  return await request('GET', '/api/recommend/routes', null, true);
}
// 别忘了在 module.exports 中导出

// 页面中使用
const res = await api.getHotRoutes();
if (res.success) { /* ... */ }
```

### 场景 D：添加一个全新的校园模块页面
**步骤**：
1. 创建目录 `pages/新模块/`
2. 从已有模块（如 `pages/express/`）复制 4 个文件
3. 修改 `.js` 中的 `moduleName: '新模块标识'`
4. 修改 `.json` 中的标题
5. 在 `app.json` 的 `pages` 数组中注册新页面路径
6. 在后端 `moduleController.js` 和路由中无需修改——10 模块共用同一套 API
7. （可选）在 `pages/_shared/base.js` 的 `moduleConfig` 中添加模块配置

**关键**：后端的 `/api/module/:module` 路由已支持任意模块名，无需修改后端代码。新模块只需指定 `moduleName` 标识即可直接工作。

### 场景 E：修改底部导航栏
**涉及文件**：
- `app.json` 的 `tabBar.list`（配置项）
- `custom-tab-bar/`（自定义导航栏代码）
- `images/tabbar/`（图标资源）

### 场景 F：修改首页布局或功能
**涉及文件**：`pages/index/index.js`、`.wxml`、`.wxss`、`.json`

### 场景 G：修改管理后台
**涉及文件**：`backend/admin/` 目录下的 HTML/JS/CSS 文件

## 七、数据流向

```
 用户操作
   ↓
 页面 JS 调用 api.xxx()
   ↓
 utils/api.js 的 request() 方法
   ↓ 携带 JWT Token
 后端 Express API (/api/xxx)
   ↓
 controller → model → MySQL
   ↓
 返回 JSON { success, data, ... }
   ↓
 页面更新 this.setData({...})
   ↓
 WXML 模板自动重新渲染
```

## 十、注意事项

1. **永远不要修改 `/api` 下任何路径的前缀**，后端路由固定。
2. **模块页面的数据流已经抽象好**（base.js），尽量复用而非重写。
3. **图片 URL 处理**：后端返回的相对路径（如 `/uploads/xxx.png`）在 `api.js` 中自动补全为 `https://app.suyu.ink/uploads/xxx.png`。
4. **登录状态**：通过 `app.globalData.isLogin` 或 `wx.getStorageSync('token')` 判断。
5. **app.json 中未注册的页面无法跳转**，新增页面记得注册。
6. **修改 `api.js` 时**，不需要改动 `fixUrl`、`fixImageUrls`、`request`、`getToken`、`setToken`、`clearToken` 这些基础方法。
