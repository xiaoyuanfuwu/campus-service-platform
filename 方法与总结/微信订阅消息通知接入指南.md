# 微信订阅消息通知接入指南

适用于「校园同行」小程序任意模块发布页，添加"有人接单时微信通知发布者"功能。

---

## 一、前置条件

1. 在微信公众平台（mp.weixin.qq.com）**订阅消息**中申请模板，拿到模板 ID
2. 当前模板 ID：`{{WECHAT_TEMPLATE_ID}}`
3. 模板字段对照表（去后台查，不同模板字段不同）：

| 模板字段 | 含义 | 示例值 |
|---------|------|--------|
| `thing17` | 留言内容 | 帖子标题 |
| `phrase8` | 消息类型 | 接单通知 |
| `time3` | 发送时间 | 06/25 23:59 |
| `phrase25` | 当前进程 | 张三 已接单 |
| `thing7` | 备注 | 请及时联系对方 |

## 二、前端改动（3 步）

以快递待取 `pages/express/` 为例，复制到其他模块页面即可。

### 2.1 发布表单加开关（WXML）

在"立即发布"按钮上方加：

```xml
<view class="card form-card">
  <view class="notify-row">
    <view class="notify-info">
      <text class="notify-label">🔔 微信消息通知</text>
      <text class="notify-hint">有人接单时通过微信服务号通知你</text>
    </view>
    <switch checked="{{notifySubscribed}}" bindchange="onNotifySwitch" color="#00A693"/>
  </view>
</view>
```

### 2.2 开关逻辑（JS）

```js
// data 中加入
notifySubscribed: false,
notifyTemplateId: '{{WECHAT_TEMPLATE_ID}}',

// 开关处理函数
onNotifySwitch(e) {
  const checked = e.detail.value;
  if (!checked) {
    this.setData({ notifySubscribed: false });
    return;
  }
  wx.requestSubscribeMessage({
    tmplIds: [this.data.notifyTemplateId],
    success: (res) => {
      const accepted = res[this.data.notifyTemplateId] === 'accept';
      this.setData({ notifySubscribed: accepted });
      if (accepted) {
        wx.showToast({ title: '已开启消息通知', icon: 'success' });
      } else {
        wx.showToast({ title: '你选择了拒绝，接单后将收不到通知', icon: 'none' });
      }
    },
    fail: () => {
      this.setData({ notifySubscribed: false });
      wx.showToast({ title: '授权失败，请重试', icon: 'none' });
    }
  });
},
```

### 2.3 发布时传给后端

在 `onSubmitPublish` 的 `createModulePost` 调用中加两个字段：

```js
const { notifySubscribed, notifyTemplateId } = this.data;
// ...
const res = await api.createModulePost(moduleName, {
  // ... 原有字段
  notifySubscribe: notifySubscribed,
  notifyTemplateId: notifySubscribed ? notifyTemplateId : '',
});
```

发布成功后重置：`notifySubscribed: false`

## 三、后端改动

**位置**: 服务器 `root@{{SERVER_IP}}`，项目 `/www/wwwroot/campus-service/backend/`

### 3.1 通知服务（已完成，直接复用）

文件 `src/services/wechatNotify.js` 提供三个函数：

```js
const { notifyOrderTaken } = require('../services/wechatNotify');

// 发送接单通知
notifyOrderTaken(
  publisher,        // 发布者对象（需含 openid, nickName）
  { title },        // 帖子信息
  { nickName },     // 接单人信息
  templateId        // 模板 ID
)
```

### 3.2 控制器修改

在 `src/controllers/moduleController.js` 中：

**create（发布）**——已在 `title` 校验前插入 notify 合并逻辑，自动生效，无需修改。

**takePost（接单）**——已在 `res.json` 前插入通知发送逻辑，自动生效，无需修改。

### 3.3 如果要用在其他非 module 接口（如拼车 carpool）

需要：
1. 在对应 controller 顶部加 `require('../services/wechatNotify')`
2. 发布时把 `notifySubscribe` + `notifyTemplateId` 存入数据
3. 接单/加入时查发布者 openid → 调 `notifyOrderTaken`

### 3.4 重要注意事项

⚠️ `ModulePost.findById` 返回的行经过了基础模型 `rowToObject` 处理，MySQL 字段 `creator_id` 被映射成了 `creator`（直接是数字，不是对象）。

获取发布者 ID 时用：
```js
const publisherId = post.creator;  // ← 直接用，不是 post.creator.id
```

⚠️ 每次改完服务器端代码都要重启：
```bash
ssh root@{{SERVER_IP}} 'pm2 restart campus-service-server'
```
